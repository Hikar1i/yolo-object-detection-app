# 当前架构

- `src/app.py`：Streamlit 单入口，六个标签页；侧栏提供全局推理参数、模型上传和模型选择。
- `src/config.py`：集中定义模型标识、模型目录、默认参数与 200 MB 上传上限。
- `src/utils.py`：图片处理、历史 CSV、日志；`get_available_models()` 合并官方模型与本地权重，`save_uploaded_model()` 校验并保存上传文件。
- `src/detector.py`：Ultralytics YOLO 加载和推理。官方权重使用原有名称，本地权重使用明确的绝对路径；页面与模型对比分别复用既有缓存。
- `src/api.py`：可选 FastAPI 服务，模型列表和推理模型范围仍为内置官方模型。

## 上传数据流

侧栏 `.pt` 上传 → 点击保存 → 校验文件名、非空、后缀和大小 → 在 `models/` 内写临时文件 → 以硬链接原子发布最终文件（存在同名目标时失败）→ 清理临时文件 → 自动选择新模型。

模型列表扫描直接位于 `models/` 的 `.pt` 文件，忽略目录、符号链接和临时文件。上传阶段不反序列化权重；实际推理时沿用检测器的加载与异常处理。只适用于可信来源的 YOLO 目标检测权重，不提供模型覆盖、删除或匿名公共上传。

模型选择与对比共用模型发现函数，历史 CSV 的字段与来源标识不变；自定义权重的参考基准显示“暂无数据”。

推理精度：`InferenceConfig.half_precision` 保持布尔接口，通过 `precision_kwargs` 适配安装库的 `quantize` 或旧版 `half` 参数，供图片、批量、视频及跟踪调用共用。
